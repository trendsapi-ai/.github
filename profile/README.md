# Trends API

A Google Trends API alternative with one REST endpoint for trend data from 27 platforms (53 data sets), including Google Trends, TikTok, YouTube, Amazon, Reddit, Pinterest, Steam and npm, returned as clean JSON with a normalized 0 to 100 trend score.

- **Sources:** Google Search, Images, News and Shopping, YouTube, TikTok, Pinterest, Amazon, Wikipedia, app stores, npm, PyPI, Steam, plus live boards and posts from Reddit, X, Instagram, Bluesky, Hacker News and Polymarket
- **Five calls:** time series, growth over any window, live top-trend boards, context (what people are posting about a keyword) and top posts for a hashtag
- **SDKs and MCP:** use it from code, or from Claude, Cursor and ChatGPT
- **Free tier:** 100 requests a month, no credit card. Pay-as-you-go credit packs when you need more

## Connect

| How | Endpoint |
